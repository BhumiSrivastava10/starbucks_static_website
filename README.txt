# ☕ Starbucks Landing Page

A modern and visually appealing Starbucks-inspired static website developed using **HTML, CSS, and JavaScript**.

This project focuses on creating an attractive coffee shop landing page with a clean user interface, smooth animations, interactive elements, and responsive design.

## 🚀 Features

* Modern Starbucks-inspired UI design.
* Responsive layout for mobile, tablet, and desktop.
* Attractive hero section.
* Coffee menu section with product cards.
* Smooth scrolling effects.
* CSS animations and transitions.
* Hover effects on buttons and images.
* Scroll reveal animations.
* Interactive mobile navigation bar.

## 🛠️ Technologies Used

* **HTML5** – Website structure.
* **CSS3** – Styling, animations, transitions, and responsive design.
* **JavaScript** – Interactive navigation and scroll animations.

## 💻 How to Run Locally

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in your browser.

4. Alternatively, use the Live Server extension in VS Code.

## 🎯 Project Purpose

The main objective of this project is to improve frontend development skills by implementing modern website layouts, responsive design, CSS animations, transitions, and JavaScript interactions.
