STARBUCKS-INSPIRED STATIC WEBSITE
=================================

Files:
- index.html  : Website structure and content
- style.css   : Layout, responsive design, transitions and animations
- script.js   : Mobile menu, scroll reveal and footer year

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder in Visual Studio Code.
3. Open index.html in your browser, or use the VS Code Live Server extension.
4. Internet is required for Google Fonts and the Unsplash sample photos.

CUSTOMIZATION:
- Change text and image URLs in index.html.
- Change colors near the top of style.css inside :root.
- Change interactions in script.js.

This is an independent, static practice project inspired by Starbucks' visual style.
It is not an official Starbucks website and is not affiliated with Starbucks.
